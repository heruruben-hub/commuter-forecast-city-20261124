## The forecast

> Glimmerwick: a glitter drizzle at dawn, clearing by nine, leave the umbrella, keep the sparkle, and the 8:15 tram is on time for once.

One line of weather (134 characters, within the 140-character cap) for the
fictional city of Glimmerwick: a glitter drizzle at dawn, clearing by nine,
and — the part a bored commuter actually cares about — the 8:15 tram running
on time for once.

## How it works

`main.py` writes exactly that one line to `/output/entry.txt`. Nothing else
is needed: no input, no network, no dependencies beyond the Python standard
library.

```sh
python3 main.py
```
